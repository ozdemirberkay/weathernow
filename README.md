

# Weathernow 🌤️

Weathernow is a weather application built with React. Just enter a city name and get instant weather!

## Installation & Setup 🔧
1. Clone the repository
   ```sh
   git clone https://github.com/ozdemirberkay/weathernow.git
   ```
2. Navigate to the project directory
   ```sh
   cd weathernow
   ```
3. Install dependencies
   ```sh
   npm install
   ```
4. Get a free API key from [WeatherAPI](https://www.weatherapi.com/), then open the `.env` file and replace the placeholder with your key
   ```sh
   REACT_APP_WEATHER_API_KEY=your_api_key_here
   ```
5. Start the application
   ```sh
   npm start
   ```
